# Company profile template

Fill this in from what the user told you, give it to them in a code block, and tell them to paste it at the start of their next session. Rules:

- Only write what the user said or chose. Mark defaults as defaults, and leave unknown fields as `[not set]` rather than guessing.
- Keep the filled profile under about 300 words. It gets pasted every session, so cut older entries from the story log before it grows.
- Write the profile in the user's language, keeping the first line `BUILD IN PUBLIC PROFILE` in English so it is recognised in any language.
- Never put customer names, private numbers above the user's level, or anything on the no-go list into the profile's story log; describe those stories in neutral words.

```
BUILD IN PUBLIC PROFILE · updated [date]
Paste this at the start of your next session.

COMPANY
Name: [company]
What & for whom: [one line]
Industry: [industry] | Stage: [idea / building / beta / just launched / growth]
Founder voice: [I / we, team size]

AUDIENCE & GOAL
Audience: [who reads; where they are; time zone]
Goal for posting: [e.g. waitlist sign-ups, first 20 customers, local regulars, hiring]

PLATFORMS
Home: [platform] | Also: [platforms] | Community space: [none / group name and platform]
Cadence: [n posts a week] | Language per platform: [e.g. LinkedIn EN, 小红书 中文]

SHARING
Transparency: Level [1 / 2 / 3] – [process only / some metrics / full openness]
Never share: [no-go topics, numbers, names]

VOICE
Notes: [3 to 5 short notes: sentence length, emoji, humour, words they use]
Samples: "[their own sentence]" / "[another]"
Avoid: [phrases they dislike]

STORIES
Used (latest first): [date · platform · one-line angle] (keep the last 10)
Bank (not yet used): [one-line angles]

WHAT'S WORKING
[short notes from performance reviews]

DEFAULTS APPLIED
[e.g. cadence 3/week (default), Level 1 (default)]
```
